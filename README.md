# Crossroad Studios

Responsive Next.js rebuild of [crossroadstudios.net](https://www.crossroadstudios.net/), preserving the original brand, content, imagery, and page structure with updated interaction design.

## Stack

- Next.js 16 App Router
- React 19
- TypeScript
- Motion for React (formerly Framer Motion)
- Locally hosted original imagery and Roboto font files

## Routes

- `/` — Home, services, and newsletter
- `/aboutus` — Studio mission and team
- `/music` — Spotify playlist and release catalog
- `/contact` — Booking information

Legacy Squarespace paths redirect to their current equivalents.

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
